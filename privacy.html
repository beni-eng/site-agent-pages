איזה מידע הכלי ניגש אליו

לאחר שבעל חשבון הגוגל מאשר זאת במפורש, הכלי ניגש ל:

  • Gmail: רק מיילים שבעל החשבון סימן לטיפול (בתווית ייעודית), וקבצי ה-PDF המצורפים אליהם. הכלי מוסיף תוויות לסימון מיילים שטופלו, ושולח דוחות תזכורת מהחשבון.
  • Google Drive: רק תיקיות וקבצים שהכלי עצמו יצר. הכלי שומר שם עותקים של המסמכים, ומנהל הרשאות צפייה בתיקיות אלה לפי הוראת בעל החשבון.

כיצד המידע משמש

המידע משמש אך ורק לזיהוי סוג המסמך, חילוץ נתוני בדיקה, שמירה מסודרת בדרייב, והפקת דוחות לבעל החשבון. המידע אינו נמכר, אינו מושכר ואינו משמש לפרסום או לאימון מודלים.

עיבוד ואחסון

  • תוכן מסמכי ה-PDF נשלח לעיבוד לשירות Google Gemini API (בחשבון בתשלום, ללא שימוש בתוכן לשיפור מוצרי גוגל).
  • הנתונים שחולצו (שם אתר, תאריכים, ממצאים וקישור לקובץ) נשמרים במסד נתונים מאובטח בשירות ענן.
  • הגישה לכלי ולנתונים מוגבלת למפעיל הכלי ולבעל החשבון.

ביטול גישה ומחיקה

בעל החשבון יכול לבטל את הגישה בכל עת בהגדרות האבטחה של חשבון הגוגל שלו (Third-party apps). לבקשת בעל החשבון, הנתונים השמורים במסד הנתונים יימחקו. הקבצים בדרייב שייכים לבעל החשבון ונשארים אצלו.

שימוש בנתוני Google

השימוש והעברה של מידע שהתקבל מ-Google APIs יעמדו במדיניות הנתונים של Google API Services, כולל דרישות השימוש המוגבל.
